# ЯРГУ_СпортПРОГ 🦾

**Наработки студента группы ПМИ-13 Осипова Дениса за 2022-2023 год**

## 📚 Содержимое

Здесь собраны полезные материалы и решения задач, связанные с подготовкой по спортивному программированию. Основные направления включают:

- 🧭 **Геометрия**: наработки для решения задач на плоскости и в пространстве.
- 📊 **Коллекция Set**: эффективные методы работы с множествами в контексте спортивного программирования.
- 🌳 **Реализация деревьев**:
  - Бинарные деревья
  - Деревья отрезков (Segment Tree)
- 🔄 **Сортировки**:
  - Merge Sort
  - Bubble Sort
  - Shake Sort
- 🔥 **Динамическое программирование**:
  - Задачи на НВП (наибольшая возрастающая подпоследовательность)
  - Задачи "Черепашка"
- 🧮 **Теория чисел**:
  - Базовые задачки по числовым теоремам и вычислениям
- 🔐 **Хеш-функции для строк**: базовое описание и реализация хеширования строк.

## 🛠️ Полезные материалы

Этот репозиторий представляет собой сборник решений, которые можно использовать для подготовки к олимпиадам по программированию, а также для выполнения лабораторных и практических работ по спортивному программированию.
